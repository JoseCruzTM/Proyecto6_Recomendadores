# Proyecto 6 - Sistemas Recomendadores

Este proyecto implementa tres sistemas de recomendación utilizando el dataset de películas de MovieLens.

## Dataset

Descargar los siguientes archivos y colocarlos dentro de la carpeta `data/`:

- movies_metadata.csv
- credits.csv
- keywords.csv

El dataset puede obtenerse desde:
https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset
